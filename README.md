# 📚 BookshopSite — Книжковий інтернет-магазин

Цей репозиторій містить вихідний код проєкту **BookShelf**, розробленого в рамках дипломної роботи. Проєкт являє собою повноцінний вебдодаток для перегляду, пошуку та замовлення книг.

---

## 🎯 Мета проєкту
Створення сучасного, інтуїтивно зрозумілого та швидкого інтернет-магазину книг, що забезпечує користувачів зручним інструментом для пошуку літератури, а адміністраторів — системою управління каталогом.

## ✨ Основний функціонал (Features)

### Для користувачів:
* **Каталог книг:** Перегляд списку доступних книг із зображеннями обкладинок, описом, ціною та інформацією про авторів.
* **Пошук та фільтрація:** Розумний пошук за назвою, автором чи жанром; фільтрація за категоріями, ціною та рейтингом.
* **Кошик покупця (Shopping Cart):** Додавання товарів, зміна кількості, розрахунок загальної вартості замовлення.
* **Оформлення замовлення (Checkout):** Зручна форма для введення даних доставки та оплати.
* **Адаптивний дизайн (Responsive UI):** Коректне відображення на мобільних пристроях, планшетах та десктопах.

### Для адміністраторів (опціонально):
* Управління каталогом (додавання, редагування, видалення книг).
* Відстеження статусів замовлень.
