# BookShelf — вебзастосунок для продажу та обміну книг

BookShelf — це дипломний вебзастосунок для розміщення, перегляду, пошуку та керування оголошеннями про продаж або обмін книг.

Проєкт не є класичним інтернет-магазином із кошиком та оплатою. Основна ідея застосунку — дати користувачам можливість створювати власні оголошення про книги, знаходити книги в інших користувачів та зв’язуватися з продавцем через email.

---

## Мета проєкту

Мета проєкту — розробити адаптивну інформаційну систему для продажу та обміну книг у форматі мобільного вебзастосунку.

Застосунок орієнтований на простий сценарій використання:

1. Користувач реєструється або входить у свій акаунт.
2. Переглядає каталог оголошень.
3. Фільтрує книги за містом, типом оголошення або назвою.
4. Створює власні оголошення.
5. Редагує або видаляє тільки свої оголошення.
6. Зв’язується з продавцем через email.

---

## Основний функціонал

### Для користувача

- Реєстрація нового акаунта.
- Вхід у систему.
- Збереження поточного користувача в браузері.
- Перегляд каталогу оголошень.
- Пошук книги за назвою.
- Фільтрація за містом.
- Фільтрація за типом оголошення:
  - продаж;
  - обмін.
- Перегляд детальної інформації про книгу.
- Створення власного оголошення.
- Редагування власного оголошення.
- Видалення власного оголошення.
- Перегляд власних оголошень у профілі.
- Зв’язок із продавцем через email.

### Для безпеки даних

- Паролі користувачів зберігаються у хешованому вигляді.
- Користувач може редагувати та видаляти тільки власні оголошення.
- Перед створенням оголошення перевіряється існування користувача.

## Що не входить у поточну версію

У поточній MVP-версії не реалізовано:

- кошик покупця;
- онлайн-оплату;
- оформлення замовлення;
- доставку;
- статуси замовлень;
- повноцінний чат між користувачами;
- окрему адмін-панель.

Ці модулі можуть бути додані в майбутньому, але вони не є основною частиною дипломного MVP.

## Основні API-маршрути

API-маршрути використовуються для взаємодії frontend-частини з backend-сервером.  
Frontend надсилає запити на сервер, а сервер працює з базою даних MySQL і повертає відповідь.

---
Авторизація
POST /api/register
POST /api/login
PUT /api/users/:id

Оголошення
POST /api/listings
GET /api/listings
GET /api/listings/:id
GET /api/my-listings/:userId
PUT /api/listings/:id
DELETE /api/listings/:id
